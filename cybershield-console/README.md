# CyberShield Console

The frontend dashboard for **CyberShield VisionX**, providing real-time AI cybercrime detection, victim assistance, and law enforcement anomaly scoring.

## Tech Stack
- **Framework:** React 18 + Vite + TypeScript
- **Styling:** Tailwind CSS + Shadcn / Radix UI
- **Routing:** React Router v6

## Getting Started

```bash
# Install dependencies
npm install

# Start local development server
npm run dev
```

The application runs locally at `http://localhost:8080`.
